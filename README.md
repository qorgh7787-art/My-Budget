# 나만의 메모장

카테고리별로 기록을 정리하고, 날짜별 캘린더로 돌아볼 수 있는 개인용 메모장 웹앱입니다.
별도 서버 없이 브라우저의 `localStorage`에만 데이터가 저장됩니다.

## 기능
- 홈: 전체 기록 목록 보기 + 검색
- 목록보기: 캘린더에서 날짜를 선택해 해당 날짜의 기록만 보기
- 카테고리: 추가/수정/삭제, 색상 구분
- 설정: 프로필(닉네임/색상), 백업 파일 내보내기/가져오기

## 실행 방법
`index.html` 파일을 더블클릭해서 브라우저로 열면 바로 사용할 수 있습니다.
Vercel 등에 배포할 경우, 이 저장소를 그대로 연결하면 `index.html`이 사이트로 표시됩니다.

## 주의
백업 파일(`.json`)에는 개인 기록이 담기므로, 공개 저장소에는 올리지 않는 것을 권장합니다.
